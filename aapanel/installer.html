Configuração inicial

Seu G-Fit, pronto para configurar.

Conecte o PostgreSQL, prepare a API e compile a interface React. O código de instalação aparece no log do projeto Node.js no aaPanel. Esse assistente funciona somente na primeira instalação.

1Instale Node.js 22 e PostgreSQL, crie um banco e um usuário no PostgreSQL com permissões nesse banco.
2No aaPanel, crie um Node.js Project apontando para a raiz do G-Fit e use npm run aapanel, Project Port 3344, com Mapping e HTTPS. Se escolher outra porta livre, configure o mesmo número no comando e no Mapping.
3Preencha os dados e confirme a instalação. O instalador prepara o aplicativo e cria somente o primeiro administrador.
